# WormholeGateway Assets

The renderer currently uses the Win32 GDI path, so these assets are kept as portable source material for a future GPU renderer.

- `shaders/starfield.vert` and `shaders/starfield.frag`: animated starfield pass.
- `shaders/wormhole.vert` and `shaders/wormhole.frag`: curved tunnel and energy-particle pass.
- `fonts/README.md`: font policy for the desktop UI.
- `textures/README.md`: texture slots reserved for nebula and space dust maps.
